# Оформление сайта «В своём ритме»

Основа — прежние `nutrition-site/dist/styles.css`, `assets/mark.svg` и `PROJECT-NOTES.txt`. Уточнение пользователя от 2 ноября 2026 года: компактнее блоки и меньше декора.

Единственный источник токенов — `:root` в `nutrition-site/dist/styles.css`.

- Палитра сохранена: молочный `#f7f6f0`, текст `#303c30`, вторичный `#66705f`, шалфейный `#e6ebdf`, зелёный акцент `#43573d`, линии `#d8ddcf`, персиковый `#f1e4d8`.
- Шрифты: Georgia для заголовков, системный Arial для текста и управления. Отдельные шрифты из сети не загружаются.
- Типографическая шкала: 12, 14, 16, 18, 20 пикселей; крупные заголовки масштабируются через общие токены. Вторичный текст проверяется на каждом фоне; на цветных поверхностях используется основной цвет текста.
- Отступы: 4, 8, 12, 16, 24, 32, 48, 64 пикселя. Интервал разделов — 48 пикселей на широком экране, 32 на узком.
- Единый радиус — 8 пикселей. Контейнер — до 1160 пикселей. Декоративные цветы, повёрнутые подписи, наложенные карточки и тени убраны.
- Общая длительность переходов — 120 мс; при `prefers-reduced-motion` переходы отключены. Геометрия кнопок не меняется при наведении.
- Все шесть страниц используют одинаковую шапку, навигацию, кнопки и подвал. На телефоне меню раскрывается кнопкой, закрывается по Escape и после выбора страницы. Без JavaScript ссылки остаются доступными.
- Форма включается после установки обработчиков. При недоступном скрипте показывается прямое обращение по email.

Новые содержательные разделы и факты не определяются дизайном: состав страниц задан только [картой из стратегии](SITE_STRUCTURE.md).
