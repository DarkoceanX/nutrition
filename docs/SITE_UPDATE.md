# Обновление сайта по карте страниц стратегии

Дата: 2 ноября 2026 года. Основание — указание владельца использовать таблицу «Карта страниц» из раздела 7 `nutrition_brand_strategy.docx`. Таблица сверена с исходным DOCX. Выбранное оформление: компактнее блоки и меньше декора.

## Результат

Созданы ровно шесть самостоятельных страниц: **Главная, Обо мне, Консультация, Материалы, Контакты и документы, Клуб**. Соответствие файлов исходной таблице и недостающие сведения перечислены в [карте переноса](SITE_STRUCTURE.md).

Сохранены палитра, шрифты, знак и фотография проекта. Уменьшены отступы, убраны декоративные наложения и тени. Размеры и длительности переходов собраны в общие токены. [Правила оформления](DESIGN.md) ссылаются на `styles.css` как на единственный источник токенов.

Общее меню отмечает текущую страницу. На телефоне оно раскрывается кнопкой и закрывается после перехода, по Escape и при нажатии вне меню. Без JavaScript ссылки остаются доступными. Форма и FAQ перенесены на «Консультацию», сведения о данных — на «Контакты и документы».

Биография, образование, опыт, точная цена, статьи и юридические документы не выдумывались. На соответствующих страницах обозначено отсутствие публикаций. В материалах использован прежний учебный рабочий лист. Клуб представлен как будущий пилот с добровольным обращением по email. Автоматической подписки, приёма оплаты и обещания даты запуска нет.

## Повторение

Сайт должен работать через механизм превью. Из корня рабочей копии:

```bash
node qa/browser/check.mjs
node qa/browser/export-preview.mjs
node qa/browser/check-offline.mjs
node qa/browser/demo.mjs
```

Сценарии используют назначенный `VIBEFORGE_SESSION_PORT` / `PORT`; если переменная не передаётся командам, добавить `--url` с фактическим локальным адресом превью. Подготовка Playwright описана в [первом отчёте](BROWSER_AUDIT.md). Для ZIP нужен Python 3. `demo.mjs --verify-only` проверяет уже записанные ролики без повторной записи. Временные файлы размещаются в игнорируемом `.cache/browser-check/`.

Исходники изменены в рабочей копии. Публикация Sites, её аудитория, домен и общая инфраструктура не менялись. Доставка реального письма и готовность услуги к продажам не проверялись.
